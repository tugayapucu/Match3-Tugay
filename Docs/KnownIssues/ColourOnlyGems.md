# Normal gems differ mainly by colour

Status: Deferred; accessibility / release concern, not addressed in Phase 11.

The six normal gems (Red, Green, Blue, Yellow, Purple, Orange) share one octagonal gem silhouette and are told apart mainly by colour. Players with colour-vision deficiency may confuse some pairs (for example Red and Green, or Blue and Purple). The HUD goal icon uses the same sprites, so it inherits the issue. The specials are not affected: each has its own shape.

Possible later work: give each colour its own silhouette or inner symbol (a source-art change), check the set with a colour-blindness simulator and in grayscale, and consider an optional colour-blind mode. This is art/presentation only: `TileType` identity and every Core rule stay unchanged.
